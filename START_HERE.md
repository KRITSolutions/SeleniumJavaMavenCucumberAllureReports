## 🚀 Quick Start Guide

### Step 1: Clone Repository
```bash
git clone https://github.com/your-repo/SeleniumJavaMavenCucumberAllureReports.git
cd SeleniumJavaMavenCucumberAllureReports
```

### Step 2: Install & Run
```bash
mvn clean install
mvn clean test
```

### Step 3: View Reports
```bash
mvn allure:serve
```

That's it! Your tests will run and reports will open in your browser.
